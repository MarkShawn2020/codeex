# Codeex 0.4.1

Codeex 0.4.1 修复了 macOS 后台生命周期和应用身份边界。任务流式更新、启动准备与
自动重启不再把 Codeex 强制切到前台，本地安装也只保留一个可见的 Codeex 运行界面。

## 主要变化

- 后台启动器不再因轮询、状态更新或首次权限检查激活 Codeex 窗口。
- 运行体使用独立、正确的 macOS 应用身份，不继承隐藏启动器的 LaunchServices 状态。
- 启动器被替换、退出或异常终止时，管理进程会停止所属运行体，不再残留并占用控制端口。
- 菜单栏“显示 Codeex”和插件中心仍可在用户主动操作时切换到前台。

## 系统要求

- Apple Silicon Mac
- macOS 13 或更高版本
- 已安装并至少启动一次官方 Codex Desktop（路径为 `/Applications/ChatGPT.app`）

## 安装

1. 下载 `Codeex-0.4.1-arm64.dmg`。
2. 退出正在运行的旧版 Codeex。
3. 打开 DMG，把 Codeex 拖入“应用程序”并替换旧版本。
4. 启动 Codeex；首次准备运行体时保持官方 Codex 安装在 `/Applications/ChatGPT.app`。
