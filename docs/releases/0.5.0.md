# Codeex 0.5.0

Codeex 0.5.0 新增 Prompt Config 和 Safe Archive 两个插件，并修复了官方 Codex 更新后
应用无法启动的问题。

## 主要变化

- Prompt Config：在 Codex 原生的指令链上分层配置 system、user、project 三级提示词，
  可读写 `config.toml` 的 `developer_instructions` 以及全局和所选项目的 AGENTS 指令
  文件。入口位于插件管理页和模型切换器旁。
- Safe Archive：归档仍被其他 Codex 客户端占用的会话时，不再直接失败，而是说明该会话
  正被谁占用，并可选择「稍后归档」——等活跃写入方释放线程后自动完成。对话框提供一键
  复制诊断信息。
- 修复官方 Codex 更新后重新分包生产代码时，Safe Archive 因为改写点被拆分到不同 chunk
  而拒绝构建、导致应用无法启动的问题。
- 修复后台启动器仍在、完整 Codex 运行体已退出时，重新打开 Codeex 不会恢复窗口却误报
  成功的问题。
- 两个新插件都默认不安装，可在插件管理页按需启用；启用后需要重启运行体。

## 系统要求

- Apple Silicon Mac
- macOS 13 或更高版本
- 已安装并至少启动一次官方 Codex Desktop（路径为 `/Applications/ChatGPT.app`）

## 安装

1. 下载 `Codeex-0.5.0-arm64.dmg`。
2. 退出正在运行的旧版 Codeex。
3. 打开 DMG，把 Codeex 拖入“应用程序”并替换旧版本。
4. 启动 Codeex；首次准备运行体时保持官方 Codex 安装在 `/Applications/ChatGPT.app`。
