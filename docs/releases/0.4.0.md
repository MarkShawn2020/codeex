# Codeex 0.4.0

Codeex 0.4.0 是首个公开 macOS 版本。它以已安装的官方 Codex Desktop 为只读输入，
在本机生成独立的增强运行体，并在完整 Codex 界面中提供可独立安装、卸载的本地插件。

## 主要变化

- 打开 Codeex 后直接进入完整 Codex 界面，可继续创建任务、运行 Agent、操作代码以及
  使用 `~/.codex` 中的 Skills、MCP、账号和任务历史。
- Codeex Tab 内置插件管理，首发包含 Lovinsp、Daemonize 与 Archive Sidebar。
- Lovinsp 可在 production renderer 中检查元素，并定位到对应 production bundle 源码。
- 增加“完全磁盘访问权限”状态、首次启动引导、系统设置直达入口和菜单栏入口。
- Codeex 与官方 ChatGPT 使用独立的应用标识和 Electron profile，可同时安装和启动。
- 公开安装包不包含官方 Codex 二进制；首次启动会从本机
  `/Applications/ChatGPT.app` 准备私有运行体。

## 系统要求

- Apple Silicon Mac
- macOS 13 或更高版本
- 已安装并至少启动一次官方 Codex Desktop（路径为 `/Applications/ChatGPT.app`）

## 安装

1. 下载 `Codeex-0.4.0-arm64.dmg`。
2. 打开 DMG，把 Codeex 拖入“应用程序”。
3. 首次启动后按引导在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”中开启 Codeex。
4. 重启 Codeex，等待首次运行体准备完成。
